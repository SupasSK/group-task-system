## ข้อจำกัด
- hash chain ไม่มีกุญแจลับ ผู้ที่เข้าถึงฐานข้อมูลได้เต็มสิทธิ์และคำนวณ hash ใหม่ทั้งสายจาก `activity_compute_hash` ได้ จะแก้ประวัติโดยการตรวจภายในไม่พบ การป้องกันกรณีนี้คือเทียบกับ hash ล่าสุดที่พิมพ์ไว้ในรายงาน (`ParticipationSummary` พิมพ์ลำดับและ hash ล่าสุด) ซึ่งเก็บไว้นอกระบบ
- การแทรกแถวที่ทดสอบเป็นแบบต่อท้าย การแทรกกลางสายทำไม่ได้โดยตรงเพราะลำดับ (`seq`) ต้องต่อเนื่อง
