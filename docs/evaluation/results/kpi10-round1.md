- คำขอที่ล้มทั้งหมดเป็นขั้นแรกของ journey (`GET /login` จาก Vercel) คำขอไป Supabase 99,456 ครั้งใน 3 ครั้งไม่ล้มเลย

- ตรวจหลังรันด้วย k6 ผู้ใช้คนเดียว 20 ครั้ง: ได้ 200 จำนวน 16 ครั้ง และ **403 พร้อม header `x-vercel-mitigated: challenge`** 4 ครั้ง คือระบบป้องกันบอทของ Vercel ส่งหน้า challenge (ต้องรัน JavaScript) ให้ไคลเอนต์ที่ไม่ใช่เบราว์เซอร์ ส่วน curl ทั่วไปและเบราว์เซอร์จริง (Lighthouse, Playwright ใน KPI อื่น) ได้ 200
- สรุป: เกณฑ์ไม่ผ่านจากการที่ Vercel ปฏิเสธไคลเอนต์อัตโนมัติ ไม่ใช่จากความสามารถรับโหลดของระบบ ผู้ใช้จริงที่ใช้เบราว์เซอร์จะผ่าน challenge ได้ แต่ผลนี้ต้องรายงานว่าไม่ผ่านตามเกณฑ์ที่กำหนดไว้ ไม่เปลี่ยนเกณฑ์ย้อนหลัง
