## กิจกรรมที่นับ
- A: ความเห็น 7 ครั้งในวันเดียว → นับ 5 (สถานการณ์ 8)
- B: การตัดสินใจ 2 + แก้ลิงก์ผลงาน 1 → 3
- C: แก้คำอธิบายงาน 1 (ไม่ใช่ลิงก์ผลงาน ไม่นับ) → 0
- L: สร้างกลุ่มและสร้างงาน (ไม่นับ) → 0
- a สูงสุด = 5
