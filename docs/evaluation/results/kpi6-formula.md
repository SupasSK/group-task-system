# KPI-6 สูตรคะแนนการมีส่วนร่วมที่ใช้คำนวณอิสระ (บันทึกก่อนเปิดดูหน้าเว็บ)

สูตรนี้เขียนจากคำอธิบายที่ระบบแสดงใต้การ์ดคะแนน และค่าคงที่ในเกณฑ์ (ภาระงาน 40, ตรงเวลา 25, กิจกรรม 20, สม่ำเสมอ 15, กิจกรรมไม่เกินวันละ 5) สคริปต์ `evaluation/kpi6-participation.mjs` คำนวณตามสูตรนี้จากข้อมูลดิบในฐานข้อมูล แล้วจึงเปิดหน้าเว็บอ่านค่า

สำหรับสมาชิก m แต่ละคน (นับหัวหน้าด้วย):

- น้ำหนักงาน w = คะแนนความสำคัญ (low 1, medium 2, high 3, urgent 4) + คะแนนความยาก (easy 1, medium 2, hard 3)
- ทีมของงาน = คนหลัก (`assigned_to`) + ผู้ร่วมทำที่สถานะ `accepted` เท่านั้น
- งานที่เสร็จของ m = งาน `completed` ที่ m อยู่ในทีม
- points(m) = ผลรวม w / จำนวนคนในทีม ของงานที่เสร็จของ m
- onTime(m) = จำนวนงานที่เสร็จของ m ที่ไม่มีกำหนดส่ง หรือ `completed_at` ≤ `deadline`
- rejected(m) = จำนวนแถว `task_responses` ของ m ที่ `response = 'rejected'`
- activity(m) = ผลรวมรายวัน (ตามเวลาประเทศไทย) ของ min(5, จำนวน log ที่นับ) โดย log ที่นับคือ `comment_added`, `decision_added` และ `task_updated` ที่ `changes` มี `work_url`
- totalWeeks(m) = max(1, floor((เวลาที่โหลดหน้า − เวลาเข้ากลุ่ม) / 7 วัน) + 1), activeWeeks(m) = จำนวนสัปดาห์ (นับจากเวลาเข้ากลุ่ม) ที่มี log ใดก็ได้ของ m
- totalPoints = ผลรวม w ของงาน `completed` ทุกงานที่ทีมไม่ว่าง, fairShare = totalPoints / จำนวนสมาชิก

คะแนน:
- ภาระงาน = 40 × min(1, points / fairShare) (0 ถ้า fairShare = 0)
- ตรงเวลา = 25 × onTime / จำนวนงานที่เสร็จ (0 ถ้าไม่มีงานที่เสร็จ)
- กิจกรรม = 20 × activity / activity สูงสุดในกลุ่ม (0 ถ้าสูงสุดเป็น 0)
- สม่ำเสมอ = 15 × min(1, activeWeeks / totalWeeks)
- คะแนนรวม = ผลรวมทั้งสี่ (ค่าจริงก่อนปัดเศษ), ร้อยละของกลุ่ม = round(points / totalPoints × 100)

เกณฑ์ผ่าน: |คะแนนรวมที่แสดง − คะแนนรวมที่คำนวณ| ≤ 0.5 ทุกคน และตัวเลขประกอบตรงกันทุกตัว (เกณฑ์ฉบับที่ 2)
